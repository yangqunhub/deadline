# 📅 Deadline 任务聚合 MVP

> 把大学生手机里的十几处散落通知(QQ群/微信/PPT/PDF/学习通等)自动变成可执行的提醒任务

**当前状态**: v2.1 跑通 - 纯前端 H5 + 任务拆解(checklist) ✅
**最后更新**: 2026-06-06

---

## 🎯 这是什么

MVP 阶段核心闭环只有一件事：**上传 → AI 提取 → 确认 → 列表**。
不做任务管理 / 分类 / 优先级 / 智能排期 / 推送。

---

## 🚀 怎么用

### 1. 起服务（如果没在跑）

```bash
cd "C:\Users\羊群的windows\Desktop\deadline"
python -m http.server 8765
```

或者任何静态服务器都行（Vite / npx serve 都可），纯静态。

### 2. 浏览器打开

**http://localhost:8765/**

### 3. 填 API 配置

第一次打开会自动弹设置面板（顶部右上角 ⚙️ 也能再开）：

- **Base URL**：点预设链接一键填
  - 豆包：`https://ark.cn-beijing.volces.com/api/v3`
  - 通义千问：`https://dashscope.aliyuncs.com/compatible-mode/v1`
  - OpenAI：`https://api.openai.com/v1`
  - OpenRouter：`https://openrouter.ai/api/v1`
- **API Key**：你的 key（仅存浏览器 localStorage）
- **模型名**：vision 模型
  - 豆包：`doubao-1-5-vision-pro-32k-250115`
  - 通义：`qwen-vl-plus`
  - OpenAI：`gpt-4o-mini` / `gpt-4o`

填完先点 **🧪 测试连接** 验证一下。

### 4. 上传/粘贴 → 提取 → 确认 → 入库

- 上传图片（JPG/PNG/WEBP，≤5MB）**或** 粘贴文本 **或** 两者叠加
- 选来源类型（QQ/微信/PDF/纯文本/其他）让 AI 更准
- 点 **🤖 提取任务**
- AI 返回后**逐条确认/编辑**（标题、截止时间、类型、说明）
- 点 **✓ 全部入库** → 任务进待办列表

### 5. 任务列表

顶部 tab 切换：
- **待办**：按 deadline 升序，红色 = 3 天内 / 过期
- **已完成**：点 ✓ 完成
- **已取消**：点 ✕ 取消

每条任务：完成 / 取消 / 删除 / 重新打开。

## 💾 数据格式（localStorage `dlm_tasks`）

```json
[
  {
    "id": "uuid",
    "title": "高数作业",
    "description": "P78 习题3-5",
    "deadline": "2026-06-10T23:59:00+08:00",
    "type": "homework",
    "urgency": "medium",
    "remind_before": [3, 1],
    "remind_times": ["08:00"],
    "estimated_prep_days": 2,
    "is_recurring": false,
    "recurrence": null,
    "checklist": [
      { "id": "c-uuid1", "text": "列 3 个候选选题方向", "done": true },
      { "id": "c-uuid2", "text": "找 5 篇参考文献", "done": false }
    ],
    "last_completed_at": null,
    "confidence": 0.95,
    "source": "qq",
    "status": "pending",
    "created_at": "2026-06-05T12:00:00.000Z"
  }
]
```

type 枚举：`homework` / `exam` / `registration` / `assignment` / `other`
status 枚举：`pending` / `done` / `cancelled`
urgency 枚举：`high`（重要）/ `medium`（普通）/ `low`（次要）— 任务本身的重要/紧急程度，跟 deadline 无关
remind_before：自由勾选 1/3/7/14 天的子集 — 提前几天提醒（仅单次任务）
remind_times：每天的具体提醒时刻，如 `["08:00", "21:00"]`（单次和周期任务都有，最多 3 个）
estimated_prep_days：AI 估的制作周期（1-30天），仅用于推 remind_before 默认值
is_recurring：是否周期任务
recurrence：`{ freq: weekly|biweekly|monthly|custom, interval_days, recurrence_dates:[ISO], start_date, end_date }`
checklist：`[{ id, text, done }]` — 任务拆解步骤（仅单次任务有，周期任务无进度概念所以不显示）
last_completed_at：周期任务"本次完成"时间戳，下次发生时间自动跳过今天

### 单次 vs 周期任务 UI 区别

- **单次任务**：显示 🎯 重要度 + 🔔 提前几天 + ⏰ 具体时刻 + 紧迫度色条
- **周期任务**：**不显示**重要度/提前几天/紧迫度色条（没有 deadline 远近概念），只显示 ⏰ 具体时刻 + 频率标签

### 周期任务

- **每周/每两周/每月/自定义**（每 N 天）
- 用月历点选具体日期来定义（每周/每月都从点选的日期里提取"周几"或"几号"）
- 有 start_date + end_date，end_date 留空 = 无限重复
- "完成"只标记**本次**（记录 last_completed_at），下次发生时间自动跳过今天
- 卡片显示紫色频率标签（如 `📅 每周 周二·四`、`📆 每月 10·22 号`、`🔁 每 3 天`）
- 排序按"下次发生时间"升序

### 🧩 任务拆解（智能 checklist）— v2.1 新增

AI 提取主任务后,会进一步把任务拆成 3-7 步可执行 checklist,让用户"知道从哪步开始做"。

**两阶段流程**：

```
上传图 → AI 提取主任务
       ↓
确认页:每张卡显示 [🧠 智能拆解] 按钮
       ↓ 点按钮
全屏模态弹出 → AI 问 1-3 个澄清问题
              (字数/类型/进度 等)
       ↓ 用户一次答完
AI 拆出 3-7 步 checklist
       ↓
确认页/编辑弹窗: 用户能增删改任意步
       ↓ 入库
列表卡片: 显示进度条 + 可勾选
         全部勾上 → 任务自动变 ✅ 已完成
```

**澄清问题设计原则**（AI 系统 prompt 约束）：
- 必是单选（选项互斥且穷尽），用户体验最好
- 问的是"能影响拆解粒度"的事（字数/类型/进度），不是任务已有信息
- 简单任务（deadline < 3天）→ 0-1 个问题
- 复杂任务（deadline > 7天 或 exam/assignment）→ 2-3 个问题

**颗粒度**（按 AI 判断的制作周期）：
| 周期 | 拆几步 |
|---|---|
| ≤2 天（签到/小作业） | 3 步 |
| 3-7 天（PPT/小论文/报名） | 4-5 步 |
| 7-14 天（视频/中等论文） | 5-6 步 |
| >14 天（期末考/毕设） | 6-7 步 |

**步步骤质量要求**：
- ✅ 动词开头（"列 3 个候选选题方向"）
- ❌ 不能是名词（"大纲"）
- ✅ 必要时括号备注关键细节（"查重(目标 <15%)"）
- ✅ 用户答案（字数/进度）体现在步骤备注里

**周期任务不显示 checklist**（没有"完成度"概念，所以省略）。

**支持两条编辑路径**：
- 确认页：新建时拆解
- 列表卡片 → ✏️ 编辑：入库后改步骤、改勾选状态

### 双维度分类（**正交独立**）

| 维度 | 计算方 | 视觉 | 作用 |
|---|---|---|---|
| **紧迫度** | 自动按 deadline 算（<1天=红 / 1-3天=橙 / >3天=绿） | 卡片左侧 4px 色条 | 一眼看出"哪个该先做" |
| **重要度** | AI 给默认 + 用户可改 | 任务名前"重要/普通/次要"彩色徽章 | 标记任务性质（期末考/日常/顺手） |
| **提醒提前量** | AI 按制作周期推默认 + 用户可自由勾选 | 复选框 1/3/7/14 天 | 决定"提前几天提醒我" |

**关键**：这三个维度**互不绑定**。视频作业=普通+提前7天，普通作业=普通+提前1天，期末考=重要+提前3天，都合理。

**提醒默认勾选（按 AI 判断的制作周期）**：
- 制作周期 ≤1天（签到）：☐1
- 制作周期 2-3天（PPT）：☑3 ☑1
- 制作周期 4-7天（视频/小论文）：☑7 ☑3 ☑1
- 制作周期 >7天（期末考复习/毕设）：☑14 ☑7 ☑3 ☑1

## ⚠️ 已知限制（MVP 阶段，故意砍）

- ❌ **无推送** — H5 打开看，后期再接短信/邮件/小程序
- ❌ **PDF 未支持** — 文件选择器限定 image/*
- ❌ **数据在浏览器** — 清缓存 = 丢，后期再上 SQLite/云
- ❌ **key 存在浏览器** — 公开部署前必须改成后端代理
- ❌ **无登录** — 单设备单用户
- ❌ **跨设备不同步** — MVP 故意砍

## 🐛 调试

- **F12 Console** 看报错
- **CORS 错误**：部分国内服务（豆包等）浏览器直调可能拦，备用方案：
  1. 用 OpenRouter / OpenAI（已知支持跨域）
  2. 最小后端代理 — 联系作者(本地有 v1 Node 后端可参考,未公开)
- **AI 返回非 JSON**：F12 看 Network 里的 raw response，可能是 prompt 漂了，调 `app.js` 里的 `SYSTEM_PROMPT`
- **任务消失**：清浏览器缓存 = localStorage 没了，正常
